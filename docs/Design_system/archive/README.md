# Archive — maquettes pré-refonte terracotta

Les bundles de ce dossier documentent l'ancienne identité visuelle
("framboise" `#D9457A` + polices Baloo 2/Figtree/Caveat), remplacée par la
refonte terracotta (voir `docs/Design_system/REFERENCE.md` pour la
référence actuelle).

Conservés pour l'historique des décisions, pas comme référence de design
active — ne pas s'y fier pour une couleur, une police ou une valeur
actuelle.
