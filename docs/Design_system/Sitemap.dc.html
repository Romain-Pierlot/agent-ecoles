✓
Académie = filtre parallèle, pas un niveau. Elle n'apparaît jamais dans l'URL ni dans le fil d'Ariane. Sur la fiche établissement, un tag « Académie de Lyon » devient cliquable → liste les établissements de cette académie (/academie/{slug}). C'est le seul point d'entrée par académie.
✓
Porte 4 renommée « Explorer » — cohérent avec les autres portes en un mot (Demander, Chercher, Comprendre).
✓
Le niveau Ville / commune est confirmé pour la V1. Chaîne complète : Région → Département → Ville-commune → Fiche.
✓
Schéma d'URL : /region/{slug}/departement/{slug}/ville/{slug}/college/{nom-uai} — l'académie n'y figure pas.
✓
Rattachement en base, par établissement : code_commune · code_departement · code_academie · code_region — 4 clés indépendantes, l'académie n'est dérivée d'aucune des trois autres.
